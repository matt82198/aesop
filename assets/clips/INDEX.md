# Demo Clips

Five short clips showing the orchestrator and fleet in action during an autonomous development wave.

## Clips

### orchestrator-startup.gif / orchestrator-startup.mp4
**Source:** 2:30–2:40 (10 sec)  
**Shows:** Initial /power priming sequence with orchestrator health checks, backlog intake, and early phase initialization. Demonstrates the startup of the multi-agent system.

### merge-train-dispatch.gif / merge-train-dispatch.mp4
**Source:** 8:00–8:10 (10 sec)  
**Shows:** Merge train in active processing with 7 PRs merged and 15 remaining in queue. Wave cycle initialized with backlog items being dispatched to parallel agents.

### parallel-fleet.gif / parallel-fleet.mp4
**Source:** 19:00–19:10 (10 sec)  
**Shows:** Multiple agents running in parallel across different domains (security linting, doc generation, concurrent fixes). Several PRs being created simultaneously by independent agents.

### audit-closing.gif / audit-closing.mp4
**Source:** 44:00–44:12 (12 sec)  
**Shows:** Closing audit phases with findings consolidated, wave-tail agent running final checks, and multiple concurrent verification lanes operating.

### verification-gates.gif / verification-gates.mp4
**Source:** 56:15–56:27 (12 sec)  
**Shows:** Final verification dashboard with phase status (Recon, Dagger, Postverify, Briefing, Verify). Tests running and gates evaluating pass/fail status before wave completion.
