## Infrastructure & Methodology Notes

### Runner Design (`bench/run_v2_parallel.py`)

- **Parallel architecture**: ThreadPoolExecutor with configurable workers (default 8)
- **Chunked execution**: `--max-runs 180` batches to fit within 10-minute tool timeout (~6 min per batch)
- **Resume capability**: Checkpoints track (tier, task_id, repeat) — skips completed runs
- **Thread-safe I/O**: Lock-protected checkpoint appends
- **Transport abstraction**: Pluggable invokers for Anthropic and OpenAI APIs

### Pre-registration Compliance

- ✓ Machine-graded only (regex/exact-match ground truth, no model scoring)
- ✓ All 60 tasks pre-committed before v2 results (bench/tasks_frontier.jsonl, bench/ground_truth_frontier.jsonl)
- ✓ Pattern validation test suite (tests/test_frontier_slice_n60.py) confirms task integrity
- ✓ Spend tracking within $30 cap
- ✓ Honest reporting of incomplete results (Claude tiers unavailable)
