## Caveats (pre-declared, carried from v2 + Amendment 2)

1. **Sequential extension**: see the verbatim disclosure above; pooled verdicts do not replace the frozen v2 verdicts.
2. **Authoring bias**: ft61-ft100 were authored after v2 results were known (no per-model tuning; per-task table published for post-hoc audit).
3. **Transport asymmetry**: ft01-ft60 Claude runs used the claude CLI; ft61-ft100 Claude runs used direct HTTP where the classifier allowed, CLI otherwise (see breakout + refusal disclosure). gpt-4o-mini ran the OpenAI HTTP seam throughout.
4. **Statistical scope**: equivalence at +/-10pp on THIS slice; smaller gaps are not ruled out, and the slice is repo-authored, not an external benchmark.
5. **Single-shot shape**: the slice is clean-context single-shot QA with pinned answer formats; it does not measure long-horizon agentic work (see STATE next-increment design).
