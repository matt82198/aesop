# Find the release that first added --dry-run

The working directory contains `CHANGELOG.md`. Read it and find the version in which the `--dry-run` flag was first added as a behaviour change. A release that only documents an existing flag does not count.

Write only that version string (for example `1.2.3`) into a new file `answer.txt` in the working directory. Nothing else in the file.

## Done when

`answer.txt` exists and contains the correct version string on its first line.
